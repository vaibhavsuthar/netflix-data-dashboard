# 📺 Netflix IMDb Data Analysis with Tableau

This is a beginner-level data analysis project using Tableau, where I explored the Netflix Movies and TV Shows dataset (with IMDb info). The project includes visual insights on genres, countries, release trends, and ratings.

---

## 📊 Project Goals

- Understand the distribution of content by genre
- Analyze content release trends over the years
- Identify top countries producing Netflix content
- Compare average ratings across genres

---

## 📁 Dataset

- **Source:** [Netflix IMDb Dataset – Kaggle](https://www.kaggle.com/datasets)
- Columns include: Title, Genre, Country, Year, Runtime, Rating, Votes, Language, etc.

---

## 🛠️ Tools Used

- [Tableau Public](https://public.tableau.com/)
- CSV Dataset (Netflix with IMDb ratings)

---

## 📈 Dashboard Features

| Chart Title               | Description                                           |
|---------------------------|-------------------------------------------------------|
| **Genre-wise Titles**     | Bar chart of number of movies/shows by genre         |
| **Content Release Trend** | Line chart showing titles added per year             |
| **Top Countries**         | Bar chart showing number of titles by country        |
| **Average Rating by Genre** | Bar chart comparing average IMDb ratings by genre  |
